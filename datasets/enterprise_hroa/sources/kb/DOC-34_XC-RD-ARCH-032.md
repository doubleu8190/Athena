# 星辰智联研发部生产变更封网窗口与高危发布审批规范

- **制度编号**：`XC-RD-ARCH-032`
- **版本**：V1.0
- **生效日期**：`2026-12-01`
- **归口部门**：研发部（`dept_mock_rd`，含平台架构组 `dept_mock_platform`）
- **关联规范**：`XC-RD-ENG-030`（研发权限与值班规范）、`XC-RD-ONCALL-031`（值班补贴与故障复盘规范）、`XC-SEC-2026-011`（信息安全与数据分级规范）

## 一、2026 年末生产变更封网窗口

1. **封网周期**：为保障年末财务关账（`2026-12-25`）、年度绩效结项与跨年业务高可用，研发部设定年度生产变更封网期为 **`2026-12-24 00:00` 至 `2027-01-03 23:59`**。
2. **封网冻结范围**：封网窗口内全面冻结常规业务功能上线、非必要依赖升级、数据库架构重构、生产 K8s 节点大规模扩缩容及网络策略变更（如 `athena-core` 架构重构与灰度须在 `2026-12-23` 前完成收口）。

## 二、封网期 P0 紧急热修（Hotfix）双签审批红线

1. 封网期间仅允许针对 **P0 级线上核心阻断故障** 或 **高危安全漏洞（CVE CVSS >= 9.0）** 发起紧急热修发布。
2. **强制双签审批人**：任何封网期紧急发布必须同时取得以下两方书面签批（对应审批单样张 `ATT-18`），缺一不可：
   - **研发部负责人**：顾行知（`MOCK003`）；
   - **信息安全团队**：安全运营中心（`sec-ops@xingchen.local`）。
3. 紧急发布变更须在变更窗口开始前 30 分钟通知当周主备 On-Call 工程师（按 `XC-RD-ONCALL-031` 执行 15 分钟内响应保障），且操作全程须在生产堡垒机录屏审计留痕。

## 三、数据库 DDL 变更与回滚脚本强制要求

1. 无论是否处于封网期，凡涉及生产数据库 **DDL 变更**（建表、加删索引、字段类型调整或 Alembic 迁移）的高危发布，变更单**必须随单附带经预发环境实测通过的回滚脚本（Rollback SQL / `alembic downgrade` 命令）**与耗时评估。
2. 未附可验证回滚脚本或未完成预发演练的 DDL 变更单，CI/CD 发布流水线自动阻断拦截，禁止人工跳过检查。
3. 若封网期紧急热修触发指标异常（5xx 错误率连续 2 分钟超过 `0.5%` 或核心接口 P99 延迟翻倍），值班架构师（如 `MOCK005` 陆知微）须在 5 分钟内执行 `helm rollback` 与回滚脚本恢复基线，并在 48 小时内按 `XC-RD-ONCALL-031` 补交无指责故障复盘与 CAPA 整改清单。
