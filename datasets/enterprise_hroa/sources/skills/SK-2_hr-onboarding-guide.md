# 新员工入职与试用期推进指南

本技能面向星辰智联人力资源部（`dept_mock_hr`），对照《员工入职与试用期管理规范》（`XC-HR-2026-002`）与《HR 入转调离内部操作 SOP》（`XC-HR-OPS-010`）统筹新员工入职准备与试用期转正评估。

## 执行步骤

1. **检索在办入职与转正工单**：
   - 调用 `hroa_list_oa_tickets` 分别查看 `ticket_type="onboarding"` 与 `ticket_type="probation_review"` 工单；
   - 结合 `hroa_get_employee_profile` 与 `hroa_get_leave_balance` 核实关键日期、直属主管、导师及试用期考勤记录。
2. **新员工入职 T-5 筹备核查**（如 `XC1001` 陈思远 / `OFFER-2026-1108`）：
   - 核对报到日期、试用期长度（默认按合同期限，社招 P6 研发骨干经批可设 3 个月）、直属主管与入职导师（如 `MOCK005` 陆知微）；
   - 按 `XC-ADM-2026-005` 核对配发电脑型号（如 `MacBook Pro 14 M4 Pro / 36G / 1TB`）并确认 IT 备机进度；
   - 若需为新 Offer 建档，调用 `hroa_initiate_onboarding` 并通过中文审批卡片确认后再落库。
3. **试用期转正评估核查**（如 `XC1002` 许知夏，2026-11-30 到期）：
   - 检查距离到期剩余天数，确认提前 15 个工作日提醒直属主管（如 `MOCK003` 顾行知）；
   - 核对试用期累计病事假是否超过 10 天红线（未超则按期转正），并提醒转正后当年折算年假自动解锁。
4. **输出格式**：以结构化待办表格列出员工工号、姓名、关键截止日、责任人及下一步动作。
