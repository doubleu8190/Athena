# 离职交接清查与清算稽核助手

本技能面向星辰智联人力资源部（`dept_mock_hr`）与财务部（`dept_mock_fin`），依据《员工离职交接与清算管理制度》（`XC-HR-2026-003`）与《财务部离职清算与备用金稽核细则》（`XC-FIN-INT-020`）执行离职清查核验与结算复核。

## 执行步骤

1. **获取实时离职与清查状态**：
   - 调用 `hroa_get_employee_profile` 与 `hroa_check_offboarding_clearance` 核查目标员工的最后工作日与四项清查项（`work_handover`、`it_asset`、`finance_advance`、`account_access`）；
   - 调用 `hroa_get_leave_balance` 确认未休法定年假余额。
2. **执行硬性阻断红线检查**：
   - 逐项列出状态为 `blocked` 或 `pending` 的清查项、涉及资产编号/序列号（如 `IT-MBP-2023-088` / `XC-SN-88412`）或未核销备用金单号/金额（如 `FIN-ADV-2026-0914` / `2,400.00` 元）；
   - 明确结论：只要四项未全部为 `cleared`，`can_issue_certificate` 必为 `false`，**严禁开具离职证明（`XC-SEP-YYYY-NNN`）或提前放行清算款**；
   - 特别提醒：仅核销单一项（如先结清财务备用金但未归还 IT 设备）仍受阻断，不得误放行。
3. **核算未休法定年假与时间节点**：
   - 日薪基准 `月基本工资 ÷ 21.75`；未休法定年假按劳动法 `300%` 口径折算，离职清算补发 **`200%` 差额**（司龄福利年假不折现）；
   - 域账号、VPN、GitLab 及堡垒机权限于最后工作日 `18:00` 统一回收；结算款随次月 `10` 日发放。
4. **受控更新清查状态**：仅在收到明确核销凭证并由用户确认时，HR 方可调用 `hroa_update_clearance_item`（触发中文审批卡片）更新对应项。
