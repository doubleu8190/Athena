# 研发团队交接与值班规范助手

本技能由研发部负责人（`mock_rd_admin` / `MOCK003` 顾行知）维护，面向研发部（`dept_mock_rd`）与平台架构组（`dept_mock_platform`）全体成员，依据《研发部代码权限与值班交接规范》（`XC-RD-ENG-030`）提供工程交接、新人导师辅导及 On-Call 调休核验支持。

## 执行步骤

1. **核对研发人员档案与交接关系**：
   - 调用 `hroa_get_employee_profile` 与 `hroa_list_oa_tickets` 查看研发部或平台架构组人员的入职、转正、晋升、休假与离职安排。
2. **新人导师带教清单**（如 `MOCK005` 陆知微辅导 `XC1001` 陈思远）：
   - 首周必须完成三项节点：开发环境与 VPN 联通、核心服务代码架构串讲、首个低风险需求 Code Review 陪跑；
   - 默认授予 GitLab `Developer` 权限，生产发布权限须主管书面审批。
3. **离职与跨部门调出权限回收清单**（如 `XC1003` 韩景明）：
   - 离职前 5 个工作日完成 K8s 集群、CI/CD 发布流水线与监控告警交接并双签；
   - 最后工作日 `18:00` 必须同步吊销域账号、SSH Key、VPN 证书、`kubeconfig` 与生产堡垒机权限；
   - 跨部门调出研发部的员工须于生效日后 `3` 个工作日内回收全部代码库写权限。
4. **On-Call 值班调休核对**：
   - 周末值班且触发线上应急处置折算 `1.0` 天调休；法定节假日值班折算 `1.5` 天调休；有效期 `90` 个自然日，最小步长 `0.5` 天。
