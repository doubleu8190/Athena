# 绩效校准、申诉与 PIP 辅导助手

本技能归属人力资源部（`dept_mock_hr`）并跨部门授权研发部（`dept_mock_rd` 含子部门）与财务部（`dept_mock_fin`），依据《年度绩效考核、等级分布与申诉管理制度》（`XC-HR-2026-007`）与《2026Q4 绩效校准操作手册》（`XC-HR-PERF-011`）提供绩效校准与申诉支持。

## 执行步骤

1. **先查员工档案与 2026 年度绩效基线**：
   - 调用 `hroa_get_employee_profile` 与 `hroa_get_performance_review` 获取员工在职状态、当前绩效等级、PIP 标记与申诉窗口截止日；
   - 严格区分不参与年度定档的边界人群：
     - `preboarding`（如 `XC1001` 陈思远）与 `probation`（如 `XC1002` 许知夏）不参与年度绩效定档，禁止提交校准调档；
     - `resigned`（如 `XC1006` 叶舒然，状态 `archived_resigned`）已封存，严禁修改历史绩效。
2. **对照制度红线给出客观建议**：
   - 2026 年度校准窗口为 `2026-11-20` 至 `2026-12-05`，公司强制分布参考比例为 **S 10% / A 20% / B+ 30% / B 30% / C 10%**；
   - 绩效评定为 **C**（例如 `XC1008` 方若琳）自动触发 **60 天 PIP 改善计划**；
   - 员工对初评结果有异议的，须在结果公布后 **5 个工作日**内（截至 `2026-12-02`）提交书面申诉与客观事实举证。
3. **关联异动与晋升准入核验**：
   - 跨部门平调门槛为近两期绩效 `>= B`（如 `XC1004` 郑语桐初评 `A`，达标）；
   - 组内晋升 `P5 → P6` 门槛为连续两期绩效 `>= B+`（如 `XC1007` 唐逸凡初评 `S`，达标）。
4. **HR 专属受控落盘**：
   - 仅人力资源部成员可调用 `hroa_submit_performance_calibration`（触发中文审批确认卡片）执行 `calibration_adjust`、`appeal_review` 或 `pip_confirm`；业务主管（研发/财务）使用本技能时仅做校准分析与书面申诉材料起草，由 HRBP 统一提交系统落盘。
